# vread-corp.github.io

Site racine (hub) des outils et kits édités par READ FRANCE SAS : https://outils.vread.fr/

Site statique sans traceur. `robots.txt` et `sitemap.xml` (index) référencent les sitemaps de chaque outil. Le fichier `<clé>.txt` est la clé publique IndexNow (protocole indexnow.org).
